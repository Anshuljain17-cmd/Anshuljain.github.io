Business question

How can SQL help an HR team understand workforce composition, salary patterns, hiring activity and employee performance?

Data structure

  • employees: employee details, department, salary and hire date.
  • departments: department names and manager information.
  • performance: yearly employee performance ratings.

The repository describes a fictional company dataset with manually created schema and inserted records.

Queries and analysis

  • Average salary by department using aggregation.
  • Top-paid employee in each department using ranking/window functions.
  • Headcount by department.
  • New joiners by year using date-based filtering.
  • Top performer by department for 2023.

What this demonstrates

Relational joins, grouping, ranking with window functions, date filtering and translating HR questions into reproducible SQL queries.
