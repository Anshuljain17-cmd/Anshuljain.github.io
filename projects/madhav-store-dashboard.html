Project overview

This project presents a retail sales dashboard in Power BI. The public repository currently contains a Power BI template file named Madhav sales.pbit and a dashboard preview image.

How to inspect the project

  • Open the repository and download the Madhav sales.pbit template.
  • Open it in Power BI Desktop and follow the prompts to connect or provide the source data, if required.
  • Inspect the report pages, visuals, filters and data model.

What this demonstrates

Power BI report packaging and visual presentation of a retail sales analysis use case.

The public repository currently provides the template and screenshot but no accompanying README, source dataset or documented KPI definitions. This case study therefore avoids claiming specific sales results or business impact.
